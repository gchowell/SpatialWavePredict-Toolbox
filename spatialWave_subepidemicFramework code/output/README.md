# Output

The toolbox writes fitted models, forecasts, scores and diagnostics to this folder. Run the drivers from the code folder so that `output/` resolves here.

The folder ships empty. Run `Run_SW_subepidemicFramework` before the plotting and forecast functions: they need the final ranking and rank files from that run. Results from earlier versions were removed in November 2026 and remain available in the repository's Git history.
